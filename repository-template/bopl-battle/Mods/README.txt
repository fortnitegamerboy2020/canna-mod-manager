Canna Mod Manager - Bopl Battle mods

Place your actual mod ZIP files or DLLs in this folder.
Then add each mod's name, version, description and relative file path
(for example Mods/your-mod.zip) to the mods array in ../game.json.

This README keeps the Mods folder visible in GitHub's web uploader.
It is a placeholder, not a mod, and Canna does not count it as a mod.
