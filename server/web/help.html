Support tickets

Contact Canna to ask for help, report a bug, or request an invitation, even before signing in. Save the private tracking link to read and reply to staff messages; signed-in members also have My tickets. Replies appear on the ticket page. This is a ticket system, not an email inbox. Invitations are still issued by the Owner.

Hidden honeypot fields, single-use expiring verification, background proof of work, same-origin checks, and per-client and global submission limits reduce spam without a paid CAPTCHA. Tickets are stored in the encrypted server database and are visible only to their author and staff.

What is Canna?

INVITE ONLY

Canna brings a Windows mod manager and a private modding forum together. It started as a family project: one place to manage the games you play, share modpacks, and help each other make and troubleshoot mods.

Member uploads and external imports await administrator approval before community downloads; Owner imports skip the initial moderation queue, but automatic analysis still gates downloads; suspicious findings require staff review. The Admin panel has a dedicated mod review queue with a full-page source workspace: file tree, safe syntax highlighting and findings linked to file/line when available. An isolated worker reconstructs supported .NET and Java code, applies suspicious-behavior heuristics and checks ClamAV public malware signatures. Detect It Easy 3.21 adds public packer/protector signatures and heuristic scanning; additional PE checks flag high-entropy executable sections, writable executable sections and unusual entry-point layouts, including files whose extension was changed. A modified or unfamiliar packer may be flagged by structure without being named; detection is not guaranteed for every packer or VMProtect variant. Packed code is not automatically malware, and protection can prevent useful decompilation. Staff must record reasons for accepted findings. Unsupported, oversized, obfuscated or failed analysis is reported explicitly and blocks approval until reviewed; a failed worker needs a new run. Binary signature findings do not claim source line numbers. Decompiled source is reconstructed, not the original project. New imports and uploads are analyzed automatically, including imported dependencies. Required dependencies and their dependencies are imported recursively; optional dependencies can be included. Conflicting versions or cyclic graphs are rejected. Approval is a review step, not a guarantee that a mod is harmless. Members have 2 GiB of uploaded-mod storage, VIPs 5 GiB, and admins 10 GiB; each account can upload up to 500 mods and create up to 5,000 posts and profile comments. Sign-in limits are scoped to clients and accounts.

Discover starts with game cards and remembers your chosen game when you visit another page. Use the back arrow or click Discover again while viewing it to return to the game list. The desktop app detects installed Unity games in your Steam libraries and manages their mods. The website hosts discussions, mod files, member profiles and shared modpacks. Bopl Battle is the first supported catalog game; Minecraft support is being developed alongside it.

You choose the mods in a pack. Canna downloads the selected files from the community server, prepares the supported game's mod loader, and gives you vanilla and modded launch options. Sharing a pack links other members to its selections; it does not share the game itself.

Get started

  1. Join with an invitation. Ask someone in the community for an invite. On the sign-in page, enter a username, email, password and invitation code to create your account.
  2. Verify your email. Enter the code emailed to you. Later sign-ins use an email code too; you can trust your device for 30 days.
  3. Download it from the website. Run the Canna installer to set up the app. Once installed, Canna checks for application updates at startup.
  4. Connect your Canna account. In desktop Settings, click Sign in & connect account. Sign into the website, then type or paste the six-character code from Canna into its dedicated verification page. The app copies the code to your clipboard; verification happens automatically. The app then syncs the server library.
  5. Create a modpack. In Game library, choose a detected game and click Create modpack. Add mods from Discover or import your own files, choose which are enabled, then apply the pack with the game closed.
  6. Play or share. Use the game's vanilla or modded launch options. Export a local pack to share a file, or use the website's modpack sharing to create a member-only link.

Chat retention and cosmetics

Chat messages disappear after 24 hours and are removed from the active database by scheduled cleanup. Rotating backups can retain older messages until those backups are replaced. Fishing collections, coin balances and cosmetic unlocks persist until account data is deleted. Chat displays the latest 100 unexpired messages.

Type /help in the live chat for CannaBot commands. Earn 200 total coins for Angler, 500 for Emerald or 1,500 for Legend, then use /equip angler, /equip emerald or /equip legend. Badges are free cosmetics and are separate from roles and reputation.

Mod submissions and notifications

My submissions shows your uploads and imported external projects, their review status, and any denial reason. Accepted or denied entries leave this tab after seven days; accepted files remain in the library. Denial removes the uploaded file and imported project entry, records a staff reason, and notifies its submitter. Notification history is private to its recipient, limited to 500 records and retained for up to 30 days. Older entries can still be present in rotating backups and the staff audit history.

Minecraft & skins

LAUNCHER PREVIEW

Canna's Minecraft work includes instance management and Microsoft sign-in, but it is not yet a fully verified launcher. Canna’s application has been submitted and is awaiting Minecraft API access approval before account login and account skin changes can be completed. A Microsoft code being accepted does not by itself confirm Minecraft access.

Create Minecraft instances from the first card in your game library. Canna’s Microsoft application ID is bundled and cannot be edited. To sign in, open Minecraft → Microsoft account → Sign in with Microsoft. A popup displays the code and opens Microsoft's page in your browser. You can copy the code, reopen the page or cancel. Canna does not ask for your Microsoft password; enter it only on Microsoft's sign-in page.

The Skins tab opens a home feed of friendly Canna-created robot skins and loads more as you scroll. Search results also load additional pages as you scroll, until the sources have no more results. External search uses a title filter but third-party images are not guaranteed to be moderated. The tab searches multiple websites. Save a result, choose its classic or slim model, and export it as a PNG. Local skin discovery, saving and export work without a Microsoft account connection. Applying it to your account requires Minecraft API access and a Minecraft Java profile.

Library filters include Minecraft version, loader and content type. Recursive dependency imports use the chosen version and loader. Complete instance installation, compatibility checking and launcher parity are still being developed; a filter result alone does not guarantee that a pack will run.

Frequently asked questions

Can I join without an invite?

No. Canna is invite-only. Each new member receives one friend invite. The Owner can create invite waves; Admins do not have permission to issue invites.

How do I add a mod from another website?

Open Mods & modpacks and click Add mod from external site at the top, or use the same button in desktop Discover. Paste a Thunderstore, Modrinth or CurseForge project link, click Look up mod, choose a file version, then Download & add to library. The server downloads and verifies the archive, stores it encrypted, and records its source, author, version, game, loader and dependencies in the library database. Reimporting that version reuses its existing entry. Owner imports publish automatically; member and admin imports wait in Admin panel → Mod reviews. Required dependencies, including their dependencies, are imported automatically. Check Include optional dependencies too when you also want optional projects. Approval includes the imported dependency graph. Conflicting versions and cycles are rejected. CurseForge requires the Owner to configure an API key and the author to permit third-party downloads.

How do I manage logged-in devices?

Sessions stay signed in until you log out or revoke them. Open My profile → Logged-in devices, or Manage logged-in devices in desktop Settings. See device names, type, last activity and Active recently / Idle state; rename a device, log it out, or log out every other device while keeping this one. Password resets and account bans still revoke sessions. Browser names come from browser information; desktop connections use the PC name. Older sessions may have a generic name you can rename. The 30-day email verification trust is separate from session duration.

What happens after incorrect connection codes?

Five incorrect codes lock that connection request and record a security event. Codes expire after five minutes, and server rate limits restrict repeated attempts. Start a new connection from Canna if yours is locked or expired.

Is my Canna account the same as my Microsoft account?

No. Your Canna account gives access to the community and its downloads. Microsoft sign-in separately authorizes Minecraft access. Connecting one does not connect the other.

The app says “Configure a Canna account” or my library is empty. What now?

Open desktop Settings and choose Sign in & connect account. Enter the connection code on the dedicated verification page and return to Canna. Once connected, sync the server. A game must be installed and have a catalog entry to show catalog mods.

How do I enable, disable or remove a mod?

Open the pack's Content table and change the Enabled checkbox, or right-click the mod. Apply the modpack with the game closed. A required library cannot be disabled while an enabled mod depends on it. Files installed outside Canna's managed plugin directory may still load.

Will my friends need the same mods?

For mods that change gameplay, use matching mod selections and versions on each PC. A shared pack helps align selections, but it does not guarantee every third-party mod is multiplayer-compatible. Check the mod's requirements.

What happens when I delete a local modpack?

Its saved manifest moves to the local deleted folder. Undo delete restores the latest deletion during that session. Deleting the pack does not uninstall the game or remove shared local mod files.

Who can open a shared modpack link?

Signed-in Canna members. A link is not a public download permission and does not bypass membership checks. Exporting a local pack produces a file you can share separately.

Why does a skin source have no results or fail to load?

Skin websites can change their layout or block automated requests. Canna shows each source's status and offers links to search it in your browser. Other working sources can still return results.

How do roles, ranks and stars differ?

Member, VIP, Admin and Owner are permission roles. Activity ranks grow with forum participation; they do not automatically grant administration powers. Stars are reputation ratings from other members.

How are account details protected?

The website uses HTTPS. Passwords are stored as salted Argon2 hashes, not as recoverable passwords. Account identity data and stored community files use encryption at rest. Desktop account credentials use Windows protection. Email verification, email sign-in codes and expiring trusted devices add account controls.

Can I reset my password or stop trusting a device?

Use Forgot password on the sign-in page and follow the emailed code. Resend verification code helps with an unverified account. After signing in, your profile has a Forget all trusted devices action.

Does the desktop contain shared API keys?

Provider API keys and administration credentials stay on the server. Starting with Canna 0.2.15, application updates download from cannamods.vip without a shared repository token. Your device stores its own account and Minecraft login credentials encrypted with Windows DPAPI.

What happens if CurseForge is rate limited?

Configured project API keys cool down according to the provider’s Retry-After response before reuse. An available key can take over; when every key is limited, try again later. Author download restrictions still apply. Author upload tokens cannot be used for importing projects. Minecraft project links can import mods, resource packs, shaders, data packs and modpack archives; available file versions are paginated and loader labels are normalized. Imported modpack archives are downloads, not automatically installed Canna instances. Dependencies are listed for separate installation. Live CurseForge access is awaiting an approved API key.

Where do mods and updates come from?

The Canna community server supplies the mod library and shared packs after account connection. Desktop application updates use a separate release channel. Imported third-party projects retain their source information; check their descriptions and requirements before using them.

Need a hand?

Sign into the community and post in Modding help. Include your Canna version, game, modpack and exact error. For a desktop issue, the Console tab can help you find the relevant setup or game log.

If you cannot sign in, open a private support ticket, or contact the person who invited you. Keep passwords, email verification codes, Microsoft sign-in codes and account tokens out of posts and screenshots.
