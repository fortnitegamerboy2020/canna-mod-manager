Support tickets

Contact Canna to ask for help, report a bug, or request an invitation, even before signing in. Save the private tracking link to read and reply to staff messages; signed-in members also have My tickets. Replies appear on the ticket page. This is a ticket system, not an email inbox. Invitations are still issued by the Owner.

Hidden honeypot fields, single-use expiring verification, background proof of work, same-origin checks, and per-client and global submission limits reduce spam without a paid CAPTCHA. Tickets are stored in the encrypted server database and are visible only to their author and staff.

What is Canna?

INVITE ONLY

Canna brings a Windows mod manager and a private modding forum together. It started as a family project: one place to manage the games you play, share modpacks, and help each other make and troubleshoot mods.

Manually uploaded mods always require staff approval after automatic analysis, including uploads from the Owner. External imports can be approved automatically when a completed scan has no findings; suspicious findings require staff review. Older manual uploads without a recorded staff approval return to the review queue. Confirmed packing, obfuscation and malware signatures automatically deny a submission with a reason and notification. Generic packing and protection heuristics require staff review; they can flag legitimate software and do not establish malware. Denied archives stay encrypted and quarantined for staff inspection, excluded from the library and downloads. Admin panel → Logs shows automatic and staff decisions and their reasons. The Admin panel has a dedicated mod review queue with a full-page source workspace: file tree, safe syntax highlighting and findings linked to file/line when available. An isolated worker reconstructs supported .NET and Java code, applies suspicious-behavior heuristics and checks ClamAV public malware signatures. Detect It Easy 3.21 adds public packer/protector signatures and heuristic scanning; additional PE checks flag high-entropy executable sections, writable executable sections and unusual entry-point layouts, including files whose extension was changed. A modified or unfamiliar packer may be flagged by structure without being named; detection is not guaranteed for every packer or VMProtect variant. Packed code is not automatically malware, and protection can prevent useful decompilation. Staff must record reasons for accepted findings. Unsupported, oversized, obfuscated or failed analysis is reported explicitly and blocks approval until reviewed; a failed worker needs a new run. Worker permission failures are analysis errors, not suspicious-code findings, and cannot be accepted as a false positive. Binary signature findings do not claim source line numbers. Decompiled source is reconstructed, not the original project. New imports and uploads are analyzed automatically, including imported dependencies. Required dependencies and their dependencies are imported recursively; optional dependencies can be included. Conflicting versions or cyclic graphs are rejected. Approval is a review step, not a guarantee that a mod is harmless. Members have 2 GiB of uploaded-mod storage, VIPs 5 GiB, and admins 10 GiB; each account can upload up to 500 mods and create up to 5,000 posts and profile comments. Sign-in limits are scoped to clients and accounts.

Discover starts with game cards and remembers your chosen game when you visit another page. Use the back arrow or click Discover again while viewing it to return to the game list. The desktop app detects installed Unity games and Left 4 Dead / Left 4 Dead 2 in your Steam libraries. The website hosts discussions, mod files, member profiles and shared modpacks. Bopl Battle and ROUNDS have Unity modpacks; Minecraft support is being developed alongside it.

You choose the mods in a pack. Canna downloads the selected files from the community server, prepares the supported game's mod loader, and gives you vanilla and modded launch options. Sharing a pack links other members to its selections; it does not share the game itself.

Supported games and smaller windows

Discover, the game library and modpack creation show games with a Canna installation profile, including supported games that are not installed yet. Detecting a Unity game alone does not make it supported. Offline catalog caching supports the full supported-game registry; the former 100-game limit has been removed. Profiles labelled preview still need live game verification. Modrinth browsing is for Minecraft; Thunderstore lists its supported Canna profiles; CurseForge lists Minecraft and supported Steam profiles exposed by its API.

When the desktop window is smaller, Discover, modpacks and downloads can scroll the whole page so filters and actions stay reachable. Game details also scroll, and the navigation icons have their own scroll area when needed. Use the wheel or scrollbar to reach controls below the visible area. Provider download redirects are handled by Canna; author download restrictions and unavailable versions still apply.

Get started

  1. Join with an invitation. Ask someone in the community for an invite. On the sign-in page, enter a username, email, password and invitation code to create your account.
  2. Verify your email. Enter the code emailed to you. Later sign-ins use an email code too; you can trust your device for 30 days.
  3. Download it from the website. Run the Canna installer to set up the app. Once installed, Canna checks for application updates at startup.
  4. Connect your Canna account. Click Log in at the top of the desktop app. Choose desktop sign-in with your username, password and emailed code, or Authorize through the website. Website authorization opens its verification page automatically; type or paste the large six-character code shown in Canna. Once connected, the app syncs the server library and the button becomes Account, with your profile and Log out.
  5. Create a modpack. In Game library, choose a detected game and click Create modpack. Add mods from Discover or import your own files, choose which are enabled, then apply the pack with the game closed.
  6. Play or share. Use the game's vanilla or modded launch options. Open a modpack and choose Share with link to publish it directly to the server. Copy the link for signed-in friends; no ZIP export is needed. Export file remains available for offline transfers.

ROUNDS and Source addon packs

The website’s Mods & modpacks game filter includes supported games even when they have no uploads. In Upload a mod, choose the game by name; Other Steam game accepts a Steam app ID. For Left 4 Dead, the upload form shows VPK packaging and practice-launch guidance. Supported Steam games appear in the desktop Library even before installation, with dimmed artwork and a Not Installed label. Their modpack and launch controls are disabled until Steam detects the installation; use Rescan Steam after installing. ROUNDS supports BepInEx 5 modpacks, local plugin imports and Thunderstore imports through the website. Its official BepInExPack_ROUNDS loader is hosted on the Canna server. Existing plugins outside Canna’s managed folder remain unchanged.

Left 4 Dead and Left 4 Dead 2 support self-contained VPK addons, including VPK-based practice and speedrunning addons. Create a pack from the game’s Library card, add a local VPK or a ZIP containing VPKs, and choose Apply modpack. Community ZIP uploads can contain VPKs and become available after review. Desktop 0.2.35 also supports reviewed L4D2 Windows x86 Valve server plugin packages with a Canna manifest, matching DLL checksum and locally generated registration. Local addons are limited to 32 MiB per file; split VPK archives, SourceMod/Metamod packages and standalone speedrunning tools are not supported by this installer.

The button is labelled Launch modded for every supported game. Launch modded enables Canna’s selected addons and launches Steam with -insecure -console -condebug for practice. Launch vanilla disables Canna-managed addons and enables -condebug without adding -insecure. Other addons, injected plugins and custom Steam launch options are not removed. Neither mode guarantees VAC compatibility for external modifications. -insecure disables VAC for that launch; it does not enable bhopping or establish leaderboard eligibility. Use each speedrunning community’s rules for valid runs. Local L4D2 launches and Canna Auto-Hop activation were verified with VAC disabled; the original Left 4 Dead remains untested.

Play Lab: set up, recover and test

Desktop 0.2.40 · Community 0.3.57

Open the numbered section cards to choose a setup, prepare a lobby, preview a report, manage test releases or browse compatibility observations. The full-width headers work as buttons with keyboard focus and visible open/close indicators.

Open a desktop modpack and select Play Lab, or open Play Lab on the website. Shared tools cover every supported game profile. Minecraft instances have their own Play Lab entry. Tools check exact enabled mod names, versions and archive hashes, dependencies, the detected game branch/build, loader label and Canna version. Unknown information stays unknown; matching manifests does not prove that a game session will work.

Create an invite-only readiness lobby and share its invitation privately. Members choose display names; other members see readiness and chosen names, without IP addresses, device names or account identifiers. Readiness expires after 60 seconds without an update. Desktop readiness refreshes while the lab is open; the website has an Update readiness button. Lobbies expire after 24 hours. Matching the host creates an isolated candidate pack with the same available archive pins; missing releases and configuration differences require explicit review. Canna never silently switches a Steam beta.

Recovery snapshots store verified cached mod archives and mod configurations on your computer. Choose an empty dedicated backup folder and storage budget in Play Lab; automatic snapshots capture the last Canna-applied setup before replacing it. Minecraft content installs also snapshot the existing setup when automatic recovery is enabled. Mark a snapshot working after testing it. Canna retains the working snapshot and up to five other snapshots per game, within the selected budget. Restore needs the game closed, intact archives and matching game/instance versions. Recovery does not downgrade or copy worlds. World data packs and save files need their own save backup. External config files outside the supported config folder are excluded.

Diagnostics read local logs and suggest checks for dependency, version, disk, memory, checksum and locked-file problems. They do not establish the cause automatically. Create dependency-closed test halves to narrow a conflict while keeping the original pack. Shared dependencies may appear in both halves. Minecraft test candidates copy mod content and supported configuration files into a separate instance, without worlds. Use the local configuration editor for CFG, TOML or JSON files; saving requires the game closed and rejects files changed outside Canna.

Publish an experimental manifest channel for a pack. Promotion to stable requires your successful-session observation for that exact manifest, with no missing/unknown preflight information. Stable is a pack owner's recorded result, not independent certification. Community observations have pages of 50 and expire after 30 days. Manifests can be downloaded and used to make desktop candidate packs when their exact archives remain available.

Privacy is the default: no automatic telemetry or hardware fingerprint. Logs, local paths, account tokens and configuration values are excluded from shared manifests. Selected shared config digests are optional. Reports and support tickets require a preview; automatic redaction is conservative, so review the preview yourself. Community reports omit usernames and device identifiers; the server retains the submitter relation privately for moderation and removal. Support tickets remain visible to their author and staff. A distinctive mod list or free-text note may still reveal something about you.

Low-end mode reduces background Steam scanning and console polling. Local tools show Canna's memory and the memory of a game launched and retained by Canna, plus a synthetic manifest-check benchmark. These measurements stay on your device. They do not measure game FPS or guarantee performance on another PC. Unity tools include BepInEx configuration and dependency tests; Source uses the existing -insecure modded launch, logs and addon/plugin management; Minecraft uses isolated content tests and instance configurations.

Automated tests cover shared game profiles, isolated install/recovery fixtures, privacy, authorization, expiring readiness, release promotion, dependency tests and desktop/mobile browser workflows. This release has not completed new live game or multiplayer verification for every supported title. Minecraft launching still needs Microsoft/Minecraft API approval. See the repository workflow test matrix for remaining checks.

Current features

Desktop 0.2.40 · Community 0.3.57

Owner invitation management has a searchable, paginated history: filter active, used, expired or revoked invitations, sort by issuer, issuance date or the users with most invitations, recover newly generated codes and revoke one code or an entire unused wave. Generate 1–50 individual codes or a named wave. Newly issued codes are stored in the encrypted server database and only the Owner can view them. Legacy hash-only codes cannot be recovered, but active invitations can be revoked. Used codes show the recipient; revocation does not delete an existing account. Canna rescans Steam in the background every 30 seconds and when you return to the app, so new supported installations and removals update automatically. Discover detects the installed Steam branch and build ID, including public, previous and beta branches. Build IDs are not game release numbers. Declared branch/build requirements are checked; unlabelled Thunderstore mods have unknown compatibility. Canna does not switch Steam branches or claim every mod works on a beta. Original mod creators are credited separately from the member who added a file; older catalog entries use their recorded author attribution.

Chat retention and cosmetics

Chat messages disappear after 24 hours and are removed from the active database by scheduled cleanup. Rotating backups can retain older messages until those backups are replaced. Fishing collections, coin balances and cosmetic unlocks persist until account data is deleted. Chat displays the latest 100 unexpired messages.

Use Up and Down arrows in the chat input to recall your own recent sent messages and restore your draft. Type /help in the live chat for CannaBot commands. Earn 200 total Kash for Angler, 500 for Emerald or 1,500 for Legend, then use /equip angler, /equip emerald or /equip legend. Owners can adjust balances and total earned Kash in Admin panel → Kash, with a confirmation and logged reason.

Mod submissions and notifications

My submissions shows your uploads and imported external projects, their review status, and any denial reason. Accepted or denied entries leave this tab after seven days; accepted files remain in the library. Manual denial deletes the mod; automatic scan rejection quarantines it. Both record a reason and notify the submitter. Open Notifications → Clear all notifications to delete all of your read and unread alerts after confirmation. Other members’ notifications are unaffected. Dismissal markers prevent the same event from immediately returning; new events still arrive. Notification history is private to its recipient, limited to 500 records and retained for up to 30 days. Older entries can still be present in rotating backups and the staff audit history.

Minecraft & skins

LAUNCHER PREVIEW

Canna's Minecraft work includes instance management and Microsoft sign-in, but it is not yet a fully verified launcher. Canna’s application has been submitted and is awaiting Minecraft API access approval before account login and account skin changes can be completed. A Microsoft code being accepted does not by itself confirm Minecraft access.

Create Minecraft instances from the first card in your game library. Canna’s Microsoft application ID is bundled and cannot be edited. To sign in, open Minecraft → Microsoft account → Sign in with Microsoft. A popup displays the code and opens Microsoft's page in your browser. You can copy the code, reopen the page or cancel. The Skins tab opens a home feed of Canna-created leaf skins with emerald, purple, amber, mint, midnight and copper color patterns and loads more as you scroll. Applying it to your account requires Minecraft API access and a Minecraft Java profile.

Library filters include Minecraft version, loader and content type. Recursive dependency imports use the chosen version and loader. Complete instance installation, compatibility checking and launcher parity are still being developed; a filter result alone does not guarantee that a pack will run.

Frequently asked questions

Can I join without an invite?

No. Canna is invite-only. Each new member receives one friend invite. The Owner can create invite waves; Admins do not have permission to issue invites.

How do I add a mod from another website?

Open My library and click Add mod from external site at the top, or use the same button in desktop Discover. Paste a Thunderstore, Modrinth or CurseForge project link, click Look up mod, choose a file version, then Download & add to library. The server downloads and verifies the archive, stores it encrypted, and records its source, author, version, game, loader and dependencies in the library database. Reimporting that version reuses its existing entry and reviewed dependency pins; it does not replace them with newer unreviewed dependencies. An explicit rescan retains staff decisions only for the same archive hash and identical finding; changed files or findings require a fresh review. Provider downloads use a seven-day file cache; after expiry, the same button retrieves and verifies the original pinned archive. Clean scans publish automatically. Findings go to Mod reviews. Confirmed packer, obfuscator or malware signatures cause a logged denial; generic protection, high entropy and other uncertain packing heuristics require staff review. Manually uploaded mods always require staff approval. Required dependencies, including their dependencies, are imported automatically. Check Include optional dependencies too when you also want optional projects. Approval includes the imported dependency graph. Individual Thunderstore mods keep the chosen mod version and retrieve current active releases of their required dependencies, including transitive dependencies, with each shared dependency resolved once. Active deprecated packages can still be imported when required by another mod; they pass the same analysis and review checks. Thunderstore modpacks retain declared dependency versions.
