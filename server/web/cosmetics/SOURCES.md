# Canna profile cosmetics

The 16 frames and three abstract banners are original Canna vector artwork.

The classic MW2 banner collection contains 296 unchanged images from
https://github.com/IcyStarFrost/mw2-callcards-remastered at commit 204c7705bccf6bedefaf2b72690b5f80ffb260d9.
Each catalog entry retains the source URL, original Git blob and local SHA256.
